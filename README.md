# Janela Chalets

موقع Janela Chalets — Next.js (App Router) + TypeScript + Tailwind CSS v4 + Framer Motion.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000).

للبناء للإنتاج: `npm run build` ثم `npm start`.

## بنية المحتوى

كل بيانات الشاليهات (الاسم، الموقع، المرافق، الأسعار، روابط الخرائط، التقييمات) موجودة في
ملف واحد: [`src/data/chalets.ts`](src/data/chalets.ts). لإضافة أو تعديل شاليه، عدّل هذا الملف
فقط — لا حاجة لتعديل أي مكوّن واجهة.

بيانات التواصل (TikTok، واتساب، إنستغرام، هاتف، بريد) في [`src/data/site.ts`](src/data/site.ts).
أي قناة غير مفعّلة متروكة `undefined` عمدًا؛ إضافة قيمة لها يُظهرها تلقائيًا في الفوتر وصفحة
"تواصل معنا" دون أي تعديل آخر.

### إضافة صور حقيقية

الصور الحالية عبارة عن لوحات بديلة أنيقة (تدرّج لوني + أيقونة) بعلامة "معاينة" صغيرة، لتبقى
الواجهة كاملة قبل توفر التصوير الفعلي. لإضافة صور حقيقية لأي شاليه، ضع الملفات في:

```
public/chalets/<slug>/hero.jpg      → صورة الغلاف في أعلى صفحة الشاليه
public/chalets/<slug>/1.jpg, 2.jpg  → صور المعرض (أي عدد، بأي ترتيب رقمي)
```

الامتدادات المدعومة: `.jpg` `.jpeg` `.png` `.webp`. بمجرد وجود الملفات، تُستخدم تلقائيًا
بدل اللوحة البديلة — لا حاجة لتعديل الكود ([`src/lib/images.ts`](src/lib/images.ts)).

### إضافة تقييمات Google حقيقية

مصفوفة `reviews` في `src/data/chalets.ts` فارغة عمدًا لكل شاليه (لم تُدرج تقييمات وهمية).
لإضافة تقييمات حقيقية، أضف كائنات بالشكل `{ rating, text, author, date? }` داخل مصفوفة
الشاليه المعنيّ.

## الصفحات

- `/` — الرئيسية (Hero + تعريف + مجموعة الشاليهات)
- `/chalets/[slug]` — صفحة كل شاليه (باتشولي، الفارس، أروما، شادو 1، شادو 2، شادو 1+2)
- `/about` — عن Janela
- `/contact` — تواصل معنا

## ملاحظات تقنية

- الموقع بالعربية بالكامل مع دعم RTL كامل (`dir="rtl"` على مستوى `<html>`).
- الخطوط: El Messiri / Amiri للعرض، IBM Plex Sans Arabic للنصوص — عبر `next/font`.
- الحركة عبر Framer Motion، مع احترام `prefers-reduced-motion` تلقائيًا (`MotionProvider`).
- الشعار في `public/logo.png` مُعالَج (خلفية شفافة + قصّ) من الملف الأصلي المحفوظ في
  `assets/logo-source.png`.
